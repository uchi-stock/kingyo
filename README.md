# kingyo（金魚掬い）

金魚掬いを体験できるWebアプリ。

## 概要

スマートフォン1台で、実際の金魚掬いに近い体験ができるWebアプリを目指す。

- **ポイの操作**: スマートフォンの加速度センサーを活用し、端末の動きをそのままポイの動きとして反映する
- **金魚の表現**: カメラ画像を用いて現実の空間に金魚を重ねて表示し、実際に目の前に金魚がいるかのような体験を提供する
